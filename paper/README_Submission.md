# CBM submission package

Journal: Computers in Biology and Medicine (Elsevier)

Recommended upload order in Editorial Manager:

1. `Cover_Letter.pdf`
2. `TitlePage.pdf`
3. `Manuscript.pdf` (single-column, double-spaced, line-numbered)
4. `Highlights.pdf` (5 items, each <= 85 characters)
5. `Supplementary_Material.pdf`
6. Source files: `Manuscript.tex`, figures, `.bbl` if requested

Suggested review model: **single-blind**. If the journal requires double-blind, replace the author block in `Manuscript.tex` and remove author-identifying text from the CRediT statement.

Preprint strategy: submit to CBM first and obtain the manuscript reference number; post to arXiv after submission. Use single-blind to avoid a mismatch between the blinded manuscript and the arXiv record.

Code policy: `Manuscript.tex` currently states that code and split definitions will be released upon acceptance. Before submission, replace the data/code availability sentence with the final anonymous repository URL. Do not use a personal GitHub URL in a double-blind manuscript.

Required declarations are already present in `Manuscript.tex`:

- CRediT authorship contribution statement
- Declaration of competing interest
- Ethical approval and data availability
- Declaration of generative AI and AI-assisted technologies
- Funding

Author details are in `TitlePage.tex`. ORCID iDs must be entered in Editorial Manager; placeholders are present in the title page.

Known items to finalize before submission:

- Add ORCID iDs.
- Insert the anonymized code repository URL.
- Confirm the corresponding author's institutional email if a `.edu.cn` address is available.
- Confirm the exact CQUPT postal address if the journal requires street-level detail.
- Confirm that the single-blind option is selected in Editorial Manager.
